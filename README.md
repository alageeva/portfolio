# Портфолио Саши Агеевой

Статический сайт: интерактивный куб, кейсы, видео, CV.

Файлы сайта находятся в public. GitHub Actions сохраняет исходные медиа в репозитории и публикует public через GitHub Pages.

В Settings → Pages выберите Source: GitHub Actions. Custom domain: sashaa.art. DNS переключается после успешной публикации.
