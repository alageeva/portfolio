# Портфолио Саши Агеевой

Подготовлен workflow GitHub Pages и сборка для адреса /portfolio/ или собственного домена.

Статус: перенос файлов сайта и медиа ещё не завершён. Папка public должна содержать полный статический экспорт сайта; после её добавления запустится публикация.

В Settings → Pages выберите Source: GitHub Actions. Домен sashaa.art следует переключать только после проверки новой публикации.
